# TeamDay v0.1.0 · 从现场，到下一步

**每天一张飞书简报，回复一个数字，把下一步变成工作初稿。**

TeamDay 把确认过的会议记录、个人待办和相关资料整理成成员专属简报。你回复编号，它起草访谈提纲、跨部门交接简报、产品机会评估或评审议程，交给你审阅。

这是 Jade 的原创团队工作流项目的首个开源预览版本，聚焦「现场记录 → 人工确认 → 每日简报 → 编号起草 → 成果留存」。

## 现在就能体验

解压项目，在已安装 Python 3.9+ 的 macOS / Linux 运行：

```bash
python3 app.py --open
```

演示无需账号或密钥；macOS 也可双击 `启动演示.command`。真实接入请按仓库中英指南完成飞书应用授权、模型配置和成员绑定。

## 本版包含

- 原始转写保留、身份校准建议、人工确认与个人 / 团队知识范围。
- 按角色生成早间 / 午间简报，待办完成与暂缓，编号生成 Markdown 草稿。
- 可选飞书私聊、数字回复、定时投递、RSS / Atom 候选和多维表格成果回写。
- 完整中英文 README、使用与接入指南；当前界面和草稿为中文。

## 验证与范围

Python 3.9 / 3.12 各 35 项测试通过；本地浏览器流程和干净安装包已验收。真实租户投递和模型供应商仍需安装者实测。资讯候选未经独立交叉核验，日历邀请、录音设备直连和 PPT/PDF 导出尚未提供。

# TeamDay v0.1.0 · From field notes to the next step

**One daily brief. One number to reply. A working draft for what comes next.**

Turn reviewed meeting context, personal tasks and relevant reading into a daily brief for each teammate. Reply with a number in Feishu to prepare an interview outline, handoff brief, product assessment or review agenda.

This first open-source preview of Jade's original team workflow focuses on one complete path: **field note → human review → daily brief → numbered draft → retained artifact.**

Run `python3 app.py --open` for an account-free synthetic demo on macOS / Linux with Python 3.9+. Live use requires a configured model, an approved Feishu app and member binding. Setup and usage guides are bilingual; the interface and generated drafts are Chinese.

All 35 tests pass on both Python 3.9 and 3.12. Browser workflows and the clean archive have been checked. Real tenant delivery still needs installation-specific verification. News candidates are not independently fact-checked; calendar invitations, recording hardware and slide/PDF export are outside this release.
